## 🌟 Featured Project

### Multi-Country School Flood Risk Analysis
> Satellite-based climate hazard assessment for 580 schools across
> Tamil Nadu (India) and Mozambique

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://tamil-nadu-school-flood-risk-ewc2sj7fhrvvtkwlpw5jzf.streamlit.app/)
[![GitHub](https://img.shields.io/badge/GitHub-View%20Code-blue)](https://github.com/ayyanarh1/tamil-nadu-school-flood-risk)

**What I built:**
- Processed Sentinel-1 SAR satellite imagery using Google Earth Engine
- Combined 6 data sources across 40+ years of climate and flood data
- Implemented full IPCC H x E x V risk framework
- Built interactive Streamlit dashboard with live public URL
- Contributed AQUEDUCT flood handler to open-source Giga Spatial library

**Tools:** GEE | Python | GeoPandas | Folium | Streamlit | ERA5 | OSMnx | IBTrACS
